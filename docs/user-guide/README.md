# Kontext user guide

Kontext is the AI-native workspace for data analysis. Connect your data,
bring your own LLM provider, and go from data questions to SQL, charts,
and automated workflows — all in one workspace.

This guide is task-oriented: each page covers one workflow, with the
screens and controls you need. Start with installation if you are new, or
jump to the page for the task you are doing.

## Get started

- [Install and start Kontext](01-install-and-start.md) — Install the released wheel, start the local server, and replace the placeholder profile.
- [Open or create a project](02-create-a-project.md) — Projects hold data sources, files, chats, and settings.

## Data

- [Connect a data source](03-connect-a-data-source.md) — Connect an external database or inspect the internal lakehouse.
- [Browse and manage files](04-browse-and-open-files.md) — Upload, organize, search, and open project files.

## Notebooks
